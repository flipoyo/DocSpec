# DocSpecs
Agnostic development philosophy for agents defined in DocSpecs.md  Using this DocSpecs file accross projects should improve the interoperability of project docs

Report, book, article are produced with ```latex```

Communication artifacts are produced with ```slidev```

## Companion files

- **`DocSpecs.md`** — the philosophy itself.
- **`AdditionalDocSpecs.md`** — a blank skeleton (section headers only) for
  a new project's own `docs/AdditionalDocSpecs.md`.
